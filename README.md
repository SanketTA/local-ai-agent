# 🤖 Local AI Agent

A simple AI assistant built using **LangChain**, **LangGraph**, **Ollama**, and **Llama 3** that runs completely on your local machine.

## 🚀 Features

* Runs locally using Ollama
* Powered by Llama 3
* JARVIS-inspired personality
* Short and concise responses
* Conversation memory support

## 🛠️ Tech Stack

* Python
* LangChain
* LangGraph
* Ollama
* Llama 3

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/local-ai-agent.git
cd local-ai-agent
```

2. Install dependencies:

```bash
pip install langchain langgraph langchain-community
```

3. Pull the Llama 3 model:

```bash
ollama pull llama3
```

## ▶️ Run

Start Ollama:

```bash
ollama serve
```

Run the application:

```bash
python app.py
```

## 💬 Example

```text
User: What is AI?

AI: AI is the simulation of human intelligence by machines.
```
